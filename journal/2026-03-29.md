# 2026-03-29

## Dory Desktop App (`desktop-app/dory`)

### Standard Window — Full Rebuild
Rebuilt `ui/standard.html` from scratch, adding features incrementally:
- Black box with green border, rounded corners, bottom-left of screen
- Header row: Dory icon/label (left), + Add and Refresh buttons (right)
- Reminder list below header — up to 2 items, each with title + time rows
- Title turns orange when reminder is within 1h
- Time format: `in 51 min` if under 1h, `Tue 3/31, 4:58 PM` otherwise
- `+3 more` footer when there are more than 2 reminders
- `⚠ Service unreachable` error shown in footer area on poll failure
- Transparent window with click-through outside the box (`setIgnoreMouseEvents` dynamic toggle via `mousemove`)

### + Add Dropdown Menu
- + Add button opens a dropdown (upward, window grows to fit)
- Option 1: **Dory Home** — opens `http://localhost:3100/dory/toddy` in browser
- Option 2: **Laundry in 1h** — POSTs a one-off reminder with `nextOccurrence = now + 1h`
- Window resizes atomically via `setBounds` to avoid flicker

### Urgency Thresholds Updated
- `> 10 min` → standard window
- `<= 10 min` and `> 0` → high window
- `<= 0` (overdue) → critical window

### High Window — Rebuilt
Clean rewrite of `ui/high.html`:
- Centered title (2-line clamp), orange live countdown, scheduled + snoozed on separate rows
- Done / +10m / +30m / +1h buttons spanning full row
- Next Up row (separator + label + title + time) when a second reminder exists
- Amber border pulse animation (border-only, no box-shadow to avoid halo bleed)
- Window width 400px, margin 20px

### Critical Window — Rebuilt
Clean rewrite of `ui/critical.html`:
- Full window box, 5px red pulsing border
- Large title, red countdown, scheduled + snoozed on separate rows
- Buttons span full row, large gap between labels and buttons
- Window margin 20px on all four sides

### Click-Through Applied to All Windows
All three windows now use `pointer-events: none` on body + `pointer-events: auto` on box,
plus dynamic `setIgnoreMouseEvents` toggling via `mousemove` IPC. Handler uses
`BrowserWindow.fromWebContents(e.sender)` so it works for whichever window sends it.

### Polling
Changed polling sync from `:30` mark to `:00` mark (top of each minute).

### Icon
Generated blue fish on black background icon (`assets/icon.png`, `assets/icon.icns`).
Set as dock icon via `app.dock.setIcon()`.

### Build
Configured `electron-builder` for macOS DMG. Moved `electron` to `devDependencies`.
Output: `dist/Dory-1.0.0-arm64.dmg`.

## UT Dashboard (`desktop-app/ut-dashboard`)

### Layout Changes
- Cards now single column (was 3-column grid), fixed width 120px
- Window: 132px wide, 550px tall, positioned 20px from left, 400px from top
- Window fixed — not movable, not resizable
- Cards wrapped in a black rounded container pushed to top
- Transparent body with click-through outside container

### Bug Fix — "To List" Badge
Old logic scanned backwards and showed stale badge if latest message had `unassigned: null`.
Fixed to stop at the most recent message that **has** the `unassigned` key, then only show badge if value is non-null.

### New — Sold Stat
Parses latest message with `content` matching `"Sold items!!!"` pattern.
Extracts CT and RD numbers, displays as `SOLD  55 / 41` in a single row on the card.
